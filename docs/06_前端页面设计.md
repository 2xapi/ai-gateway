## §2 接入模式选择器（编辑表单顶部）

```
┌─────────────┐ ┌─────────────┐ ┌────────────┐
│ ○ 官方登录   │ │ ● 保持官登  │ │ ○ 第三方API │
│  Official   │ │  +API Mixed │ │  PureApi   │
└─────────────┘ └─────────────┘ └────────────┘
选 Mixed/PureApi 时下方显示连接字段；选 Official 时连接字段折叠隐藏。
```

**联动规则**：
- `Official`：隐藏 base_url、api_key、wire_api、proxy_url、模型表格；仅保留 name/model（model 可留默认）。
- `Mixed`/`PureApi`：显示全部；选 PureApi 时在表单底部显示提示「将覆盖 auth.json，官方登录会备份，可一键恢复」。

## §3 编辑表单

| 元素 | 字段 | 校验 | API |

| 高级(折叠) | proxy_url/timeout_secs/user_agent/custom_headers/website/notes/icon | timeout 5~3600 | — |

## §7 首页今日用量摘要

首页顶栏账号/余额区域增加一个可点击的今日摘要，不展开完整图表，避免首页信息过载。统计数据来自本地网关已完成的第三方请求；示意数字不代表实际账单。

```
┌─ 当前中转站：2xapi · 主账户 ─────────────────┐
│ 今日 12.8M Tokens   命中率 42.1%   $18.46    │
│                              查看使用统计 →  │
└──────────────────────────────────────────────┘
```

| 元素 | 类型 | 行为 | API |
|---|---|---|---|
| 今日 Token | 摘要 | 显示当前 provider 今日 `totalTokens`；null 显示「暂无数据」 | GET `/api/usage/summary` |
| 缓存命中率 | 摘要 | 显示 `cacheHitRate`；null 显示「暂无数据」 | GET `/api/usage/summary` |
| 今日费用 | 摘要 | 显示已记录的 `cost`；无费用记录时显示「暂无数据」，不估算 | GET `/api/usage/summary` |
| 查看使用统计 | 链接/按钮 | 打开完整使用统计页，并保持当前 provider 筛选 | — |

## §8 使用统计页

```
┌──────────────────────────────────────────────────────────┐
│ 使用统计     [2xapi · 主账户 ▾]        刚刚同步  刷新     │
├──────────────────────────────────────────────────────────┤
│ 今日 Token │ 输入 │ 输出 │ 缓存命中率 │ 今日费用          │
├──────────────────────────────────────────────────────────┤
│ Token 活动历史                             [日聚合]      │
├──────────────────────────────────────────────────────────┤
│ 时间范围 [近7日] [近30日] [近90日]                         │
│ 每日 Token 趋势图                                       │
├────────────────────────┬─────────────────────────────────┤
│ 模型用量排行             │ 缓存效率                        │
└────────────────────────┴─────────────────────────────────┘
```

| 元素 | 类型 | 行为 | API |
|---|---|---|---|
| 中转站筛选 | 下拉菜单 | 当前 provider/全部第三方 provider；切换后刷新全部统计 | `/api/providers` + 统计接口 |
| 今日摘要 | 指标组 | Token、输入、输出、请求数、命中 Token、命中率、费用、同步时间 | GET `/api/usage/summary` |
| Token 活动 | 历史视图 | 按本机自然日显示最近时间范围的请求/Token 聚合；无数据日期保留为空 | GET `/api/usage/history` |
| 时间范围 | 分段控件 | 选择 7/30/90 日，刷新趋势和排行 | GET `/api/usage/history`、`/api/usage/models` |
| 每日趋势 | 柱状图 | 按日展示每日 `totalTokens`；历史接口当前提供日聚合，不按模型拆分 | GET `/api/usage/history` |
| 模型用量 | 排行列表 | 显示模型 Token、输入/输出、请求数、费用、占比、命中率 | GET `/api/usage/models` |
| 缓存效率 | 环形图/指标 | 显示命中率、命中 Token、输入 Token；字段缺失显示「暂无数据」 | GET `/api/usage/summary` |
| 刷新 | 按钮 | 重新读取本地 `usage-stats.jsonl` 统计快照并返回本地同步时间；不自动调用中转站账单 API | POST `/api/usage/refresh` |

**状态规则**：
- 初次加载显示骨架/加载状态，不能空白等待。
- 没有请求数据显示「今天还没有第三方中转请求」。
- 上游没有 usage、缓存或费用字段时，对应指标显示「暂无数据」，不使用原型中的演示数字。
- 统计接口失败时保留上次成功数据，并显示「上次同步时间」和重试入口。
- 费用仅展示已记录且可用的 `cost`；缺失时显示「暂无数据」，不使用演示值或估算值。

## §9 可选透明用量悬浮窗

悬浮窗不是主页面替代品，默认关闭；用户可从左侧「使用统计」页面直接点击「打开悬浮窗」，也可进入左侧「设置」主页面的「用量」分区操作。设置使用独立主页面，不使用全屏弹窗；当前原生窗口已实现独立显示/隐藏、今日 Token、输入/输出 Token、请求数、缓存命中率、透明度、置顶、鼠标穿透、悬停恢复、刷新间隔和位置记忆；收起/展开及完整统计入口保留为界面扩展位。

```
当前态（默认尺寸约 320×190）
┌─────────────────────────────┐
│ 今日 Token                 × │
│ 12.8M tokens                │
│ 输入 8.5M · 输出 4.3M       │
│ 请求 326 · 缓存命中率 42.1%  │
└─────────────────────────────┘

刷新按钮：↻
```

| 元素 | 类型 | 行为 | API/设置 |
|---|---|---|---|
| 打开/隐藏悬浮窗 | 主页面按钮 | 在「设置 → 用量」直接打开或隐藏；默认关闭 | POST `/api/settings/usage-overlay/action` |
| 透明度 | 滑块 | `60%~100%`，默认 `88%`，实时预览并保存 | `opacity` |
| 置顶 | 开关 | 默认开启；关闭后作为普通窗口 | `always_on_top` |
| 鼠标穿透 | 高级开关 | 默认关闭；开启前提示不可直接点击窗口 | `click_through` |
| 移入恢复不透明 | 开关 | 默认开启；悬浮窗移入时恢复 `100%` 便于阅读 | `restore_full_opacity_on_hover` |
| 刷新间隔 | 步进/菜单 | 默认 30 秒，范围 15~300 秒；与统计页共用快照 | `refresh_interval_secs` |
| 收起/展开 | 界面扩展位 | 预留收起/展开和信息密度切换，不影响当前独立窗口 | 本地窗口状态 |
| 拖动 | 窗口区域 | 保存窗口位置；多显示器失效时回到主屏安全位置 | `position` |
| 隐藏/显示 | 设置/窗口按钮 | 隐藏不停止网关；可通过设置或动作接口恢复 | POST `/api/settings/usage-overlay/action` |
| 打开完整统计 | 界面扩展位 | 预留从悬浮窗进入完整统计页 | `/api/usage/*` |

**状态规则**：
- 首次启动和升级后不自动创建可见悬浮窗；设置为关闭时不占用桌面空间。
- 悬浮窗只读取 UsageStats 统计接口，不自行解析响应或重复累计请求；刷新状态与统计口径一致。
- 没有统计数据时显示「暂无数据」；请求失败时保留最后成功值并显示同步时间。
- 使用 Tauri 独立透明窗口；平台能力不足时保留主页面统计功能。
- 默认可点击，鼠标穿透必须是用户主动选择；窗口被关闭后可从设置或动作接口重新显示。

## §10 交互/状态规则

- 所有请求经 `api-client.js`，统一处理 `{ok,data}`/`{ok:false,error}`，失败弹 toast。
- active 状态变更后，刷新 `/health` 以同步顶栏 access_mode。
- 表单未保存离开 → 二次确认。
- key 等敏感字段默认掩码，编辑时不回填原值（占位 `••••`），未改则不提交该字段（后端保留原值）。
- 删除 active 项 → active=null，顶栏提示「未激活」。
